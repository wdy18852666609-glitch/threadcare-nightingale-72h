BROWSER AND UI ASSETS

The application uses standard browser capabilities, including Fetch, Web Audio,
Canvas-related binary processing, and MediaDevices/getUserMedia. These are Web
Platform APIs and are not bundled third-party libraries.

The interface uses system fonts, Unicode symbols, and original HTML, CSS, and
JavaScript. No external font package, icon library, CSS framework, UI component
library, analytics SDK, or copied clinical dataset is included.

DATA NOTICE
